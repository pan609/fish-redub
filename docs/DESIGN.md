## 1. 参考分析：Fish Audio App 的视觉语言

参考素材：App Store 5 张商店截图（本地 `design/reference/`，版权原因不入库）。从截图中提取的特征：

| 特征 | 观察 | 本项目沿用方式 |
|---|---|---|
| 底色 | 偏暖的米白 `#FBF7F8`，带极淡的点阵纹理和橙色螺旋线装饰 | 页面底色用同一暖白；不做纹理，仅在空状态插画中使用橙色线条 |
| 品牌色 | 橙色 `#EF8328`～`#FF8C22`，用于标题强调词、录音按钮（渐变胶囊） | 橙色只用于**录音**和**强调**，不用于普通按钮，保持克制 |

## 2. 设计原则

1. **一屏看清流程**：主页面四张步骤卡片自上而下，已完成、进行中、未解锁三种状态一眼可辨。
2. **一个阶段只有一个主按钮**：黑色胶囊永远是"下一步"，其他操作降级为次按钮或文字按钮。
3. **状态写在卡片里**：加载、空结果、错误、重试都在所在步骤的卡片内展示，不用全屏遮罩，不用难以追溯的 Toast。
4. **声音可视化**：凡是可播放的地方都有波形和时长，播放中的波形用前景色填充表示进度。
5. **克制用色**：橙色只出现在录音和品牌强调上；错误用红色，仅限错误信息。

**对比度（v0.4 实测，WCAG 2.x 公式）**：所有文字令牌在其实际使用的背景上 ≥ 4.5:1。

| 文字 | 背景 | 浅色 | 深色 |
|---|---|---|---|
| `textTertiary` | `surface` / `bg` / `surfaceMuted` | 5.42 / 5.10 / 4.83 | 5.75 / 6.31 / 4.98 |
| `accentText` | `surface` / `surfaceMuted` / `accentSoft` | 5.54 / 4.94 / 5.01 | 8.32 / — / 6.89 |
| `successText` | `surface` / `bg` | 5.35 / 5.04 | 7.65 / — |
| `danger` | `surface` / `dangerSoft` | 6.44 / 5.64 | 6.22 / 5.55 |

例外说明：进行中步骤圆为 `accent` 底，数字改用 `#1D1D1D`（6.4:1）；录音按钮为橙色渐变底白色图标（约 2.6:1），属于 72pt 大尺寸图形且有文字提示配合，不承载文字信息。禁用控件按 WCAG 豁免，但"前置条件提示"（未解锁卡片的说明）属于信息，按正文标准执行。

### 3.2 字体

使用系统字体：iOS 为 SF Pro / PingFang SC，Android 为 Roboto / Noto Sans CJK。计时和时长使用等宽数字（`fontVariant: ['tabular-nums']`），避免跳动。

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 34 / 41 | 800 | 页面大标题（"配音"、"历史"） |
| `timer` | 48 / 56 | 700 | 录音计时 |
| `title` | 20 / 26 | 700 | 弹层标题、卡片标题 |
| `headline` | 17 / 22 | 600 | 步骤标题、列表主文字、按钮 |
| `body` | 16 / 24 | 400 | 正文、转写文字 |
| `callout` | 14 / 20 | 400 | 说明、错误信息 |
| `caption` | 12 / 16 | 500 | 时间、标签、字数统计 |

支持系统字体放大；`timer` 和 `display` 最多放大到 1.3 倍，防止破版。

### 3.3 间距、圆角、阴影

- **间距（4 的倍数）**：`xs 4` · `sm 8` · `md 12` · `lg 16` · `xl 20` · `2xl 24` · `3xl 32`。页面左右边距 20。
- **圆角**：`chip 999`（胶囊）· `button 999` · `card 20` · `sheet 28` · `input 16` · `avatar 999`。
- **阴影**：浅色模式卡片用极轻阴影（`0 2 12 rgba(29,29,29,0.04)`），深色模式不用阴影，改用 `border`。
- **点击区域**：≥ 44 × 44pt。视觉尺寸小于 44 的控件（40pt 播放、关闭按钮，行内文字按钮）用 `hitSlop` 或外层透明点击区补足，相邻控件的点击区不重叠（间距不足时缩小 hitSlop，而不是重叠）。

### 3.4 动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 步骤卡片展开 / 收起 | 高度 + 透明度 | 220ms，ease-out |
| 弹层出现 | 自底部滑入 + 遮罩淡入 | 280ms，spring |
| 录音中 | 波形竖条随电平跳动；录音按钮外圈呼吸 | 持续 |
| 加载 | 文字骨架闪烁 + 波形竖条依次起伏（"三点"替代） | 持续 |
| 生成成功 | 结果卡片淡入上移 8pt | 240ms |

尊重系统"减弱动态效果"设置：开启后关闭呼吸、起伏动画，只保留淡入淡出。

## 5. 页面设计

### 5.1 全局框架

- 底部双 Tab：**配音**（波形图标）、**历史**（时钟图标）。
- 双端都使用 `NativeTabs`（系统原生 Tab Bar）：iOS 26 为液态玻璃，iOS 旧版为系统毛玻璃，Android 为 Material 3 底部导航。页面内容延伸到 Tab Bar 下方，形成透光效果。详见 §7。
- 页面头部：大标题由原生导航栏绘制（iOS `headerLargeTitle`，滚动后收起为玻璃导航栏）；导航栏右侧只放"重新开始"按钮（v0.5：原左侧品牌标志会被 iOS 26 自动套成无响应的玻璃按钮，按 PM 反馈与重新开始合并）。Android 使用同字号（34）左对齐粗体标题与同形态圆形按钮，底部使用与 iOS 一致的浮动胶囊 Tab Bar。

> v0.2 变更：v0.1 曾把"生成配音"固定在底部玻璃承托区。画稿时发现它和浮动 Tab Bar 叠在一起，占用约 130pt 纵向空间，并且和卡片内按钮的模式不一致，因此改到卡片内。

**步骤进度条**：四段，已完成为 `textPrimary` 实心，当前为 `accent`，未到为 `waveIdle`；下方四个 `caption` 标签。

## 6. 图标规范

> PM 反馈（2026-10-26）：避免粗糙图标和 emoji 式图标。

### 6.1 规则

1. **界面中禁止使用 emoji，也不用文字符号代替图标**（如 ✕ ✓ ‹ ▶ ★）。所有图标都走统一的 `<Icon>` 组件。
2. **使用各平台的原生图标体系**，通过 `expo-symbols`（SDK 58，`SymbolView` 同时支持 iOS 与 Android）实现：
   - iOS：**SF Symbols**，默认字重 `semibold`，渲染模式 `hierarchical` 或 `monochrome`。
   - Android：**Material Symbols Rounded**（`expo-symbols` 的 `android` 名称），字重 500。
3. 动作类图标优先用**填充款**（`play.fill`、`mic.fill`），导航和工具类用线条款（`xmark`、`chevron.left`），同一区域内不混用。
4. 尺寸只用三档：**17**（行内、标签）· **20**（按钮内）· **24**（Tab、空状态）；图标颜色只取文字或强调色令牌，不单独定色。
5. 系统动效：录音中的 `waveform` 使用 SF Symbols 的 `variableColor` 动画；保存成功使用 `bounce`（只在 iOS 上，开启"减弱动态效果"时关闭）。
6. 设计稿中用 Phosphor Fill / Bold 近似 SF Symbols 的视觉；开发时以下表的系统符号为准。

## 7. 液态玻璃（iOS 26）方案

> PM 要求（2026-10-26）：真正开发时融合 iOS 26 液态玻璃效果。

### 7.1 原则

- **玻璃只用于浮在内容之上的控件层**（导航栏、Tab Bar、弹层、浮动按钮）。内容层（步骤卡片、文本、列表）保持实色，保证可读性。这与 Apple HIG 对 Liquid Glass 的要求一致。
- **优先使用系统原生组件**，让系统负责折射、高光、形变和无障碍（"降低透明度"设置开启后系统自动降级）。不用模糊加半透明去模拟玻璃。
- **给玻璃可以折射的背景**：页面底色上加两团柔和的暖色光晕（右上橙色、左下粉色，高斯模糊），来自 Fish Audio 商店图的橙色光晕元素，内容滚过玻璃控件时能看到折射。
- 运行时用 `isLiquidGlassAvailable()`（`expo-glass-effect`）判断；不可用时走"降级"列。

### 7.2 落地位置

| 位置 | iOS 26（液态玻璃） | 实现方式 | 降级：iOS 25 及以下 / Android |
|---|---|---|---|
| 底部 Tab Bar | 系统液态玻璃 Tab Bar，向下滚动时最小化 | `expo-router/unstable-native-tabs` 的 `NativeTabs`，`minimizeBehavior="onScrollDown"` | iOS 旧版：系统毛玻璃 Tab Bar；Android：Material 3 底部导航（同一个 `NativeTabs`） |
| 页面导航栏 | 透明大标题导航栏，滚动后标题收起，导航栏变为玻璃 | Stack `headerLargeTitle` + `headerTransparent` | iOS 旧版：系统模糊导航栏；Android：实色顶栏 |
| 历史详情返回、工具按钮 | 玻璃圆形按钮 | 原生导航栏按钮（iOS 26 自动为玻璃） | 普通图标按钮 |
| 录音弹层、声音选择弹层 | 浮动玻璃弹层：中等高度时四周留边、大圆角；拉到全屏时贴边 | 原生 `formSheet`（`sheetAllowedDetents`、`sheetGrabberVisible`），不设背景色，由系统绘制玻璃 | iOS 旧版：系统弹层；Android：Material 底部弹层 |
| 弹层头部关闭 / 确认按钮 | 可交互玻璃圆形按钮（按下有形变反馈） | `GlassView isInteractive` | `surfaceMuted` 圆形按钮 |
| 录音按钮外圈 | 橙色着色玻璃圆环，录音时呼吸 | `GlassView tintColor=accent` 包裹渐变按钮 | 半透明橙色圆环 |
| 结果区"分享 / 导出" | 一组玻璃胶囊按钮，相邻按钮靠近时融合 | `GlassContainer spacing` + 两个 `GlassView isInteractive` | 暖灰胶囊次按钮 |

> **编码初期先做最小验证**（审查意见 #7）：原生 formSheet 在两端的背景、档位（中等 / 全屏）、下滑关闭行为，以系统实际效果为准，验证结果写入 PLAN；若某端效果不符合预期，回退到 `GlassView` 自绘弹层背景或普通实色弹层。

### 7.3 不使用玻璃的位置

步骤卡片、文本输入框、历史卡片、播放器波形、错误提示条：保持实色，避免玻璃叠玻璃和文字可读性问题。

## 9. 文案规范

- 语气：简短、直接、说明原因和下一步；不用"出错了""未知错误"之类的空泛表述。
- 按钮用动词：录音、导入文件、确认文字、生成配音、重新生成、分享、导出、重试。
- 数字与单位之间不加空格：`10MB`、`60 秒`（中文单位保留空格）。
- 错误文案以 PRD 7.1 为准，页面内不重复造词。

## 10. 无障碍

- 所有图标按钮有 `accessibilityLabel`（如"播放原音"、"暂停新配音"、"试听 Sarah"）。
- 播放进度条设置 `accessibilityRole="adjustable"`，读出"已播放 4 秒，共 12 秒"。
- 步骤卡片读出状态："第二步，文字，待确认"。
- 录音计时每 10 秒播报一次剩余时间（仅读屏开启时）。
