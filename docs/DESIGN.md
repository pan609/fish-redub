## 1. 参考分析：Fish Audio App 的视觉语言

参考素材：App Store 5 张商店截图（本地 `design/reference/`，版权原因不入库）。从截图中提取的特征：

| 特征 | 观察 | 本项目沿用方式 |
|---|---|---|
| 底色 | 偏暖的米白 `#FBF7F8`，带极淡的点阵纹理和橙色螺旋线装饰 | 页面底色用同一暖白；不做纹理，仅在空状态插画中使用橙色线条 |
| 品牌色 | 橙色 `#EF8328`～`#FF8C22`，用于标题强调词、录音按钮（渐变胶囊） | 橙色只用于**录音**和**强调**，不用于普通按钮，保持克制 |
| 主按钮 | 近黑 `#1D1D1D` 胶囊按钮，白字（"Generate Voice"） | 每个阶段唯一的主操作都用黑色胶囊 |

| 弹层 | 纯白底，大圆角（约 28pt）；左上角圆形 ✕，标题加粗居左，右上角 ✓ | 录音弹层、声音选择弹层完全沿用 |

| 卡片 | 白底上的浅暖灰卡片 `#FBF7F8`，圆角约 20pt；头像 + 名称 + 时间，下方正文和波形 | 结果卡片、历史卡片 |

## 2. 设计原则

1. **一屏看清流程**：主页面四张步骤卡片自上而下，已完成、进行中、未解锁三种状态一眼可辨。
2. **一个阶段只有一个主按钮**：黑色胶囊永远是"下一步"，其他操作降级为次按钮或文字按钮。
3. **状态写在卡片里**：加载、空结果、错误、重试都在所在步骤的卡片内展示，不用全屏遮罩，不用难以追溯的 Toast。
4. **声音可视化**：凡是可播放的地方都有波形和时长，播放中的波形用前景色填充表示进度。
5. **克制用色**：橙色只出现在录音和品牌强调上；错误用红色，仅限错误信息。

## 3. 设计令牌（Design Tokens）

### 3.1 颜色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg` | `#FBF7F8` | `#121011` | 页面底色 |
| `surface` | `#FFFFFF` | `#1D1A1B` | 卡片、弹层 |
| `surfaceMuted` | `#F5F1F0` | `#2A2627` | 次按钮、标签、输入框、播放器底 |
| `border` | `#EEE8E7` | `#332E2F` | 分隔线、卡片描边 |
| `textPrimary` | `#1D1D1D` | `#F5F1F0` | 标题、正文 |
| `textSecondary` | `#615F60` | `#B5ADAB` | 说明文字 |
| `textTertiary` | `#A09896` | `#7D7573` | 时间、占位、未解锁步骤 |
| `primary` | `#1D1D1D` | `#F5F1F0` | 主按钮底色（深色模式反转为浅色） |
| `onPrimary` | `#FFFFFF` | `#1D1D1D` | 主按钮文字 |
| `accent` | `#EF8328` | `#FF9640` | 品牌强调、步骤编号、链接 |

| `accentSoft` | `#FFF1E6` | `#3A2616` | 强调色浅底（当前步骤标记、语言标签选中） |
| `success` | `#2E9E5B` | `#4CC27A` | 已完成步骤的勾 |
| `danger` | `#D93B3B` | `#FF6B6B` | 错误文字、删除 |
| `dangerSoft` | `#FDECEC` | `#3A1C1C` | 错误提示条底色 |
| `waveIdle` | `#D9D2D0` | `#4A4344` | 未播放部分的波形 |

所有文字与背景组合满足 WCAG AA（正文对比度 ≥ 4.5:1）；`textTertiary` 只用于辅助信息，不承载关键内容。

### 3.2 字体

使用系统字体：iOS 为 SF Pro / PingFang SC，Android 为 Roboto / Noto Sans CJK。计时和时长使用等宽数字（`fontVariant: ['tabular-nums']`），避免跳动。

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 34 / 41 | 800 | 页面大标题（"配音"、"历史"） |
| `timer` | 48 / 56 | 700 | 录音计时 |
| `title` | 20 / 26 | 700 | 弹层标题、卡片标题 |
| `headline` | 17 / 22 | 600 | 步骤标题、列表主文字、按钮 |
| `body` | 16 / 24 | 400 | 正文、转写文字 |
| `callout` | 14 / 20 | 400 | 说明、错误信息 |
| `caption` | 12 / 16 | 500 | 时间、标签、字数统计 |

支持系统字体放大；`timer` 和 `display` 最多放大到 1.3 倍，防止破版。

### 3.3 间距、圆角、阴影

- **间距（4 的倍数）**：`xs 4` · `sm 8` · `md 12` · `lg 16` · `xl 20` · `2xl 24` · `3xl 32`。页面左右边距 20。
- **圆角**：`chip 999`（胶囊）· `button 999` · `card 20` · `sheet 28` · `input 16` · `avatar 999`。
- **阴影**：浅色模式卡片用极轻阴影（`0 2 12 rgba(29,29,29,0.04)`），深色模式不用阴影，改用 `border`。
- **点击区域**：≥ 44 × 44pt。

### 3.4 动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 步骤卡片展开 / 收起 | 高度 + 透明度 | 220ms，ease-out |
| 弹层出现 | 自底部滑入 + 遮罩淡入 | 280ms，spring |
| 录音中 | 波形竖条随电平跳动；录音按钮外圈呼吸 | 持续 |
| 加载 | 文字骨架闪烁 + 波形竖条依次起伏（"三点"替代） | 持续 |
| 生成成功 | 结果卡片淡入上移 8pt | 240ms |

尊重系统"减弱动态效果"设置：开启后关闭呼吸、起伏动画，只保留淡入淡出。

## 5. 页面设计

### 5.1 全局框架

- 底部双 Tab：**配音**（波形图标）、**历史**（时钟图标）。
- **iOS 26**：使用系统原生 Tab Bar（`expo-router` 的 Native Tabs），自动获得液态玻璃效果；页面内容延伸到 Tab Bar 下方，形成透光效果。
- **其他系统（iOS 26 以下、Android）**：自定义 Tab Bar，`surface` 底 + 顶部 `border` 分隔线；Android 遵循系统手势导航留白。
- 页面头部：左侧大标题（`display`），配音页标题左侧放 Fish 风格的竖条波形标志。

| 步骤 | 状态 | 卡片内容 | 主操作 |
|---|---|---|---|

| | 导入中 | 骨架 + "正在读取文件…" | — |

| | 为空 | 警告条"未识别到有效语音" + 三个次按钮：重新录音 / 重新导入 / 手动输入 | — |
| | 失败 | 错误条（PRD 7.1 文案）+ "重试"（不可重试的错误不显示按钮，改为说明下一步） | — |

**主按钮位置**："确认文字"放在第 ② 张卡片内，"生成配音"放在第 ④ 张卡片内。每个主按钮都紧跟它所属的步骤，用户看到的是"这一步的下一步"。确认文字后页面自动滚动到第 ③、④ 步。
> v0.2 变更：v0.1 曾把"生成配音"固定在底部玻璃承托区。画稿时发现它和浮动 Tab Bar 叠在一起，占用约 130pt 纵向空间，并且和卡片内按钮的模式不一致，因此改到卡片内。

**步骤进度条**：四段，已完成为 `textPrimary` 实心，当前为 `accent`，未到为 `waveIdle`；下方四个 `caption` 标签。

### 5.4 录音弹层

| 状态 | 内容 |

| 预览 | 录音名称 + `AudioPlayer` + 次按钮"重录" + 主按钮"使用此录音" |
| 自动结束 / 后台结束 | 预览状态顶部加提示条："已达到 60 秒上限，录音已自动结束" / "录音已在切到后台时结束" |

录音中禁止下滑关闭弹层，避免误触；点 ✕ 会弹出确认"放弃本次录音？"。

### 5.5 声音选择弹层

- 头部：✕、标题"选择声音"、✓（确认并关闭）。
- 列表：每行 = `VoiceAvatar 48` + 名称 + 语言标签 + 一行简介 + 右侧 `PlayButton`（试听）。试听中该行显示一条细进度条。
- 选中行：浅 `accentSoft` 底 + 右侧对勾，头像外圈描边。
- 顶部提示一行 `caption`："所有声音都支持中英文，标签表示样例语言"。
- 关闭弹层时停止试听。

### 5.6 历史页

- 大标题"历史" + 右侧记录数。
- 列表卡片（参考 Fish "Generation" 卡片）：左上头像 + 声音名称，右上时间（今天显示 `14:05`，更早显示 `10-24 14:05`）；正文为配音文字 2 行；底部 `caption`："原音：录音 2026-10-26 14:03 · 00:12"；文字被编辑过时显示"已编辑"标签。
- 点击进入详情；左滑出现删除（Android 用长按菜单）。
- **空状态**：橙色线条波形插画 + "还没有配音记录" + 主按钮"去创建第一条配音"（切到配音 Tab）。

### 5.8 系统级反馈

| 场景 | 形式 |
|---|---|
| 步骤内错误、空结果 | 卡片内 `InlineAlert` |
| 导出成功（Android） | 底部轻提示 2 秒："已导出到所选目录" |
| 保存到本地失败 | 结果区 `InlineAlert` + "重试保存" |
| 删除确认、放弃录音 | 系统原生确认框 |
| 离线 | 页面顶部细条"网络不可用"，网络恢复后自动消失 |

## 6. 液态玻璃（iOS 26）方案

| 位置 | iOS 26 | iOS 26 以下 / Android |
|---|---|---|
| 底部 Tab Bar | 系统原生 Tab Bar，自动为液态玻璃 | 自定义不透明 Tab Bar |
| 弹层头部 ✕ / ✓ 按钮 | 玻璃圆形按钮 | `surfaceMuted` 圆形按钮 |

原则：玻璃只用于"浮在内容之上"的控件，内容卡片保持实色，确保文字可读；不做自定义模糊模拟。

## 8. 文案规范

- 语气：简短、直接、说明原因和下一步；不用"出错了""未知错误"之类的空泛表述。
- 按钮用动词：录音、导入文件、确认文字、生成配音、重新生成、分享、导出、重试。
- 数字与单位之间不加空格：`10MB`、`60 秒`（中文单位保留空格）。
- 错误文案以 PRD 7.1 为准，页面内不重复造词。

## 9. 无障碍

- 所有图标按钮有 `accessibilityLabel`（如"播放原音"、"暂停新配音"、"试听 Sarah"）。
- 播放进度条设置 `accessibilityRole="adjustable"`，读出"已播放 4 秒，共 12 秒"。
- 步骤卡片读出状态："第二步，文字，待确认"。
- 录音计时每 10 秒播报一次剩余时间（仅读屏开启时）。
