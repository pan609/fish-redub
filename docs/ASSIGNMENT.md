# 录音转写与重新配音（Transcribe & Redub）

## 任务目标

使用 Expo 框架和 Fish Audio API，实现一个支持录音、音频导入、语音转写、文本编辑、重新配音和本地历史记录的移动端应用。

用户可以录制或导入一段音频，将其转写为文字，检查并编辑转写结果，再选择一个目标声音生成新的配音。用户能够分别试听原音与新配音，并将结果保存、分享。重新配音以用户确认的文字为准，不要求保留原音的语气、节奏或时长。

核心流程：录音或导入音频 → 转写 → 检查并编辑文字 → 选择声音 → 生成配音 → 试听、保存与分享。

## 相关资料

- **公开 API 文档**：
  - [语音转写（Speech to Text）](https://docs.fish.audio/api-reference/endpoint/openapi-v1/speech-to-text)：`POST /v1/asr`，上传音频并获得转写文字。
  - [语音合成（Text to Speech）](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)：`POST /v1/tts`，提交文字及目标声音的 `reference_id`，获得生成的音频数据。
  - [声音列表（List Models）](https://docs.fish.audio/api-reference/endpoint/model/list-models)：`GET /model`，可用于开发时选取可用声音，成品可hardcode几个固定模型, 无需实现动态声音列表页面。

## 项目要求

1. 完成录音转写与重新配音主页面，以及历史记录（History）页面。录音、声音选择、结果预览可以采用页面或弹层实现，页面应清楚表达当前输入、处理阶段和下一步操作。
2. 项目须使用 Expo 脚手架创建，使用 React Native 和 TypeScript，并同时兼容 iOS 与 Android。两端的实现不要求完全一致，但应保持核心流程和交互体验一致。
3. 单用户、单说话人短音频场景。录音和导入音频均限定为 1–60 秒、文件大小不超过 10 MB；无需实现登录注册、订阅支付、声音克隆、多人说话人分离、时间戳对齐、音频剪辑或实时通话。
4. 自行选取至少 3 个可用的 TTS 声音，预置声音 ID、名称、头像和试听音频。无需实现声音搜索、筛选或动态加载。可以完整接收生成音频后再播放，不强制要求流式播放。
5. 笔试过程需全程录屏。可适当降低录屏码率和帧率，但必须确保能够清楚辨认 IDE 中的代码；无需开启摄像头。
6. 允许并推荐使用任意 AI/Agent，使用过程和 Prompt 需要包含在录屏中。
7. UI只需要适配手机端, iPad和折叠屏不做要求.

## 验收标准

1. **录音输入**：支持申请麦克风权限、开始录音、显示录音时长、结束录音、试听和重新录制。用户拒绝权限时，应说明原因并提供恢复入口。达到本题录音时长上限时应自动结束，过短或无效录音应给予明确提示。
2. **音频导入**：支持通过系统文件选择器导入 MP3、WAV、M4A 音频，并展示文件名和时长。对空文件、无法读取的文件，以及格式、时长或大小不符合要求的文件给予明确提示。用户取消选择不应被提示为错误。
3. **转写与文本编辑**：支持修改错字、增删内容，并在用户确认后进入配音步骤。转写结果为空时应提示未识别到有效语音，不自动提交 TTS；编辑后的纯空白文本也不能提交。至少能够完成中文和英文短音频的转写与配音流程。
4. **目标声音与配音生成**：支持切换并试听预置声音。配音请求必须使用用户当前确认的文字和声音，成功后能够播放真实生成音频。应明确展示转写中、待编辑或确认、配音生成中、成功及失败状态；没有真实进度数据时可显示阶段性加载状态。
5. **录音与播放切换**：原音、声音样例和新配音不能同时播放。开始录音前应停止当前播放，录音结束后应能正常试听。录音期间切到后台时，应结束录音，并在返回后允许用户试听有效录音；如果未能保存有效录音，应说明原因并允许重录。
6. **结果试听与导出**：支持分别播放和暂停原音、新配音，并显示播放进度。切换音源时应停止上一音源。生成的音频数据应能保存为本地音频文件，并通过系统保存或分享入口导出；用户取消保存或分享不应被当作失败。
7. **History 本地持久化**：成功记录至少包含本地记录标识、原音名称、原始转写文字、本次实际用于配音的文字、目标声音、创建时间，以及原音和配音文件的本地位置。
8. **异常与重试**：处理网络断开、请求超时、认证失败、额度不足、限流、接口错误、音频接收不完整和本地保存失败。
9. **双端可用性**：iOS 和 Android 均能够正常启动，完成录音或导入、转写、修改文字、选择声音、生成配音、试听、保存和历史查看。
