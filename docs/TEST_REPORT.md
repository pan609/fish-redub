## 1. 测试策略

| 层级 | 方式 | 覆盖 |
|---|---|---|
| 单元测试 | Jest，86 条 | 状态机迁移、请求守卫与取消、保存协议与恢复、错误归一化、TTS 完整性校验、文件头识别 |
| 端到端 | Maestro，双端各跑一遍（`.maestro/`） | 主流程（中 / 英）、导入校验、转写为空、换声音与过期、故障注入、录音、历史删除 |

测试音频见 `test-assets/README.md`（由 `scripts/gen-test-assets.sh` 生成）。为便于自动化定位，模拟器中的英文样本命名为 `en-m4a.m4a`、`en-wav.wav`。
